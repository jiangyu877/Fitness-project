## 使用说明

本表记录练伴 V1.0 施工过程中的重要问题、分析依据、实际修改、验收结果和后续动作。产品范围与业务规则以 [V1.0 PRD](./lianban-v1.0-prd.md) 为唯一权威来源，P01-P21 总体状态以 [产品验收台账](./lianban-v1.0-acceptance-ledger.md) 为准；本表只提供过程追踪，不替代审批或验收结论。

责任范围使用 `[产品]`、`[UI]`、`[研发]`、`[联合]` 标记。状态统一使用：

- `分析中`：正在收集证据，尚未形成可执行结论；
- `施工中`：已有修改或测试，但目标范围尚未完整验收；
- `待验收`：修改已完成，等待相应责任方复核；
- `已完成`：目标范围内已有匹配的修改和验收证据；
- `已阻断`：缺少必须由指定责任方提供的决定、批准或外部条件。

登记规则：未运行的测试不得写成通过；未提交改动不得写成稳定交付；路由存在、静态页面或单项测试不能单独证明完整产品要求通过；专业、安全、隐私、运营和部署门禁只能由对应责任方关闭。
